# Probel Suzano 🛏️

Website developed for Probel Suzano to present the store and its products and make customer contact easier.

## 🚀 Technologies

- React
- JavaScript
- HTML
- CSS
- Vite

## 🌐 Live website

https://probelsuzano.com

## ▶️ Run locally

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
